# Skills Repository

This repository is the canonical Git-backed archive for shareable Codex skills and their human-facing documentation.

## Canonical Rules

- `skills/*/SKILL.md` is canonical for runtime skill behavior.
- `docs/` contains human-facing documentation for browsing and publishing.
- `references/` folders contain supporting source material and examples.
