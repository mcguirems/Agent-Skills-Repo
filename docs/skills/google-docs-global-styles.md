## Purpose

`google-docs-global-styles` applies Mike McGuire's live Global Styles template whenever an agent creates a new Google Doc. It reads the template before each creation so later template changes take effect automatically.

## When To Use

Use this skill when creating:

- a new report, plan, summary, or other Google Doc
- a Google Doc from uploaded or converted source material
- a document whose content is generated by another skill but whose appearance should follow the Global Styles template

A document-specific formatting request overrides this default for that document.

## When Not To Use

Do not use this skill to:

- restyle an existing Google Doc unless the user requests it
- edit the source Global Styles template
- treat plain-text access as sufficient for formatted output
- apply Google Docs-specific formatting rules to another file format

## How It Works

The skill reads the live template's named styles, page setup, paragraphs, and text runs. It resolves the effective appearance of labeled samples, then copies the template or explicitly applies those styles to a new document. It reads the result back and corrects representative style or page-setup mismatches before returning the document link.

## Requirements

The agent needs access to the live template and a Google Drive or Google Docs integration capable of reading formatting and creating or copying documents. The template is an intentional live runtime dependency; its style values are not cached in the package.
