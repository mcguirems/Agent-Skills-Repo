# **Primary Navigation Logo – Route to Platform Home**

## **Description (Problem / Context)**

The mobile navigation drawer currently behaves like a desktop mega-menu, displaying all navigation items at once. This results in an overly long menu on small screens, pushes primary navigation items down, and increases cognitive load for touch users. Secondary links under “Resources” are especially contributing to menu bloat and reduced scannability.

---

## **Required Elements (Acceptance Criteria)**

1. Update the mobile navigation to use an **accordion-based navigation drawer** pattern  
2. The **“Resources” section is collapsed by default** on mobile  
3. Tapping “Resources” expands/collapses its child links in-place  
4. Primary navigation items (Home, Fitting, Sizing) remain **visible above the fold** on mobile  
5. Profile and Account sections remain unchanged (no additional collapsing at this time)  
6. Desktop navigation behavior is **unchanged**  
7. Interaction pattern should align with **Tailwind UI – Stacked Flyout Menu**  
8. Reference: [https://tailwindcss.com/plus/ui-blocks/marketing/elements/headers\#component-27e5f71ced91b88e3f6b59ca69033a83](https://tailwindcss.com/plus/ui-blocks/marketing/elements/headers#component-27e5f71ced91b88e3f6b59ca69033a83)

---

## **References / Constraints**

- Follow standard web and mobile navigation conventions  
- Maintain existing logo styling and placement  
- Refer to 901 \- MVF Platform Style-Guide \- Release 1.0 for UX and UI patterns


---

## 

## **Why This Is Needed (UX Rationale)**

This change improves mobile navigation usability without introducing new complexity or visual redesign.

1. Reduces cognitive load by limiting the number of visible choices at once  
2. Improves scan speed and touch accuracy on small screens  
3. Prevents primary navigation items from being visually buried  
4. Aligns mobile behavior with established iOS and Android navigation conventions  
5. Supports progressive disclosure for secondary content while keeping it easily accessible
