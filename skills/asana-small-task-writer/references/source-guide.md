# Source Guide

Source type: canonical small task guidance

Original file:
- `Knowledge - MVF - Asana Small Task Definition Guide.md`

Key points preserved in this skill:
- use a small-task gate before drafting
- focus on scoped UX, UI, and behavior work
- produce clear, testable acceptance criteria
- keep rationale short and user-centered
- treat the work as implementation-ready, not discovery-stage

Important note:
- the original guide treats `References & Constraints` as optional but recommended
- this skill keeps that section in every output for consistency, while allowing a brief explicit statement when no constraints are provided
