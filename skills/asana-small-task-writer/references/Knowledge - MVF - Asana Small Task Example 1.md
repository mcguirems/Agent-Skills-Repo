# **Primary Navigation Logo – Route to Platform Home**

## **Description (Problem / Context)**

The MyVeloFit logo in the primary navigation currently links to an external WordPress marketing site and opens in the same tab. This unexpectedly removes users from the platform experience and breaks a common navigation expectation where the logo functions as a reliable “Home” action.

---

## **Required Elements (Acceptance Criteria)**

1. Clicking the MyVeloFit logo routes users to the platform \[Home\] dashboard  
2. The logo no longer navigates to the external WordPress site  
3. Behaviour is consistent across mobile and desktop  
4. No new browser tabs are opened when clicking the logo

---

## **References / Constraints**

- Follow standard web and mobile navigation conventions  
- Maintain existing logo styling and placement  
- Refer to 901 \- MVF Platform Style-Guide \- Release 1.0 for UX and UI patterns


---

## **Why This Is Needed (UX Rationale)**

Ensures the logo behaves as a predictable Home action and keeps users inside the platform.

- Aligns with established UX conventions  
- Prevents accidental context switching  
- Reduces user confusion and navigation errors  
- Improves task continuity and platform stickiness
