# MVF SVG Icon Converter

Convert an SVG into exactly nine variants: one black default and eight brand colors, delivered as a ZIP. Requires Python 3, file access, XML processing, and ZIP support.

Start with [installation](Install-this-skill.md), [usage](how-to-use-this-skill.md), or [team guidance](team-instructions.md). The [skill workflow](SKILL.md) and [conversion rules](references/conversion-rules.md) govern conversion.
