# MyVeloFit Project Brief Creator

## Purpose

`mvf-project-brief-creator` turns rough project inputs into a MyVeloFit project brief in the standard seven-section markdown format.

## When To Use

Use this skill when you have a feature concept, launch idea, workstream proposal, Asana export, or planning notes and need to convert them into a complete project brief with rationale, scope, ownership, and success metrics.

Good fits include:
- feature briefs
- app initiative briefs
- launch planning briefs
- strategic update briefs
- scoped operational workstreams

## When Not To Use

Do not use this skill when the work is still too vague to describe at a project-brief level, when you need a technical specification instead of a business brief, or when a short task or ticket would be enough.
