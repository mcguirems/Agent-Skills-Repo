# How To Use This Skill

Use `$asana-new-bug-logger` in ChatGPT to create or find bug reports from Slack.
Screenshots from Slack are not added automatically. 

***

**With a Slack link**

1. Copy Link from your Slack chat
2. Open ChatGPT.
2. Type `$asana-new-bug-logger [past Slack link]`
3. ChatGPT will check for duplicates and create the bug in Asana project 021.

***

**Without a Slack link**

1. Open ChatGPT.
2. Type `$asana-new-bug-logger`.
3. ChatGPT will scan recent reports and provide possible bugs to choose from.

***

**After a bug is created**

1. ChatGPT will confirm a new bug task was created
2. Open the Asana task using the link provided.
2. Add any screenshots under **+ Attachments**. If they were posted in Slack, download them first.
3. Review the task to make sure the information is correct.
