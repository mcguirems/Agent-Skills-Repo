# MyVeloFit Working Backwards Brief

## Purpose

`mvf-working-backwards-brief` turns a MyVeloFit project brief into an Amazon-style Working Backwards document with a press release, customer FAQ, and internal FAQ.

## When To Use

Use this skill when you already have a project brief, planning notes, or equivalent launch context and want to convert it into a credible Working Backwards artifact that matches MyVeloFit positioning.

Good fits include:
- feature launches
- productized service updates
- B2C product changes
- B2B workflow launches
- internal launch-readiness exercises

## When Not To Use

Do not use this skill when the initiative is still too undefined to describe clearly, when you need a purely technical specification, or when the output should be a short task rather than a launch narrative.
