# Blazer Query Generator

Requires a privately supplied MyVeloFit `schema_main.md` or equivalent current schema context. The production schema is intentionally excluded from this public package.

This portable workflow drafts PostgreSQL for manual execution in authorized Blazer. It is not self-contained: supply private schema through reusable project/master knowledge, pasted content, file uploads, or an accessible authorized Google Doc. Optional private `Docs_main.md` provides MVF Blazer configuration.

Follow [installation](Install-this-skill.md), [usage](how-to-use-this-skill.md), and [team guidance](team-instructions.md). See [schema requirements](references/schema-requirements.md).
