# Install Blazer Query Generator

Requires a privately supplied MyVeloFit `schema_main.md` or equivalent current schema context. The production schema is intentionally excluded from this public package.

Installing the public workflow does not supply schema knowledge or execute SQL. Supply current private context separately, then review and run generated SQL manually in authorized Blazer.

Extract the ZIP. It contains exactly one skill folder, `blazer-query-generator`, with `SKILL.md` at its root. Keep all bundled files together. Import or place that folder using the host's supported skill installation mechanism.

## ChatGPT Work

Use the host's supported skill/package import mechanism if available. ZIP download alone does not install or change an existing plugin. If importing is unavailable, use the package as reference instructions in an approved project environment.

## Codex

Place the complete folder in the configured user or project skills location. Invoke `$blazer-query-generator`. Keep private runtime resources separate from this public folder.
