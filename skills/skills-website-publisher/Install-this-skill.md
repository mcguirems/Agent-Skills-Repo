# Install This Skill

These instructions install the `skills-website-publisher` skill from the downloadable archive.

## Platform-neutral install

1. Download `skills-website-publisher.zip`.
2. Unzip the archive.
3. Move the extracted `skills-website-publisher/` folder into your agent's skills directory.
4. Restart or reload your agent so it discovers the new skill.
5. Invoke the skill with a completed target skill directory:

```text
$skills-website-publisher /path/to/target-skill
```

## Codex install

1. Place the extracted folder in your Codex skills directory:

```text
~/.codex/skills/skills-website-publisher
```

2. Restart Codex or open a new session.
3. Confirm the skill appears in the available skills list.

## Requirements

- A completed source skill that is safe to distribute.
- Netlify authentication or a connected Netlify account for publication.
- Permission to publish the target skill's documentation and downloadable archive.

## Notes

The skill builds the website and handles publication, but you remain responsible for reviewing the generated copy, verifying the download package, and removing private or sensitive material before publishing.
