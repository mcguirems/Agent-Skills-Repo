# Team Instructions

Use `$TARGET_SKILL_NAME` in ChatGPT to turn a finished skill into a standalone documentation and download website.

## How to use it

1. Open ChatGPT.
2. Type `$TARGET_SKILL_NAME /path/to/target-skill`.
3. Follow the result link or choose from the options provided.
4. Complete any manual follow-up.
5. Review the output to make sure it is correct.

## Important

- The target skill must already exist and be safe to distribute.
- Netlify must be connected or authenticated before the site can be published.
