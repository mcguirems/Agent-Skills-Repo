# Install This Skill

## Recommended

Download `blog-extraction.zip`, then extract the top-level `blog-extraction/` folder into your Codex skills directory.

Typical destination:

- `~/.codex/skills/blog-extraction/`

## Manual install

If you are installing from source instead of the zip, copy this whole folder into your skills directory and keep the internal structure unchanged:

```text
blog-extraction/
  SKILL.md
  README.md
  Install-this-skill.md
  references/
  source/
```

## Notes

- Keep the folder name as `blog-extraction`.
- `SKILL.md` is the canonical runtime entrypoint.
- The `source/` folder preserves the original Claude-authored prompt source for traceability.
