# Output Templates

Use these structures when generating the two required markdown outputs.

## Full Extraction

```md
# [Article Title]

**Source:** [Full URL or file origin]
**Author:** [Author name if available]
**Published:** [Date if available]
**Organisation:** [Publication or organization]

---

[Clean article body with headings, lists, quotes, and tables preserved]

---

*Source: [Publication] - [Domain]*
```

## Coaching Summary

```md
# Coaching Summary: [Article Title]

**Source:** [Publication] / [Author if known] - [Date]
**Topic:** [One-line description]

---

## Core Concept
[Most important idea]

---

## [Section Heading]
[Coaching points only]

---

## One-Line Coaching Takeaway
> [Single-sentence takeaway]

---

*Source: [Publication] - [Domain]*
```
